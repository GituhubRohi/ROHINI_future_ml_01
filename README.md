 # ROHINI_future_ml_01
Machine Learning project for Sales and Demand Forecasting using Superstore dataset

This project predicts future sales using the Superstore dataset.

Tools Used
Python
Pandas
Scikit-learn
Matplotlib

Features
- Data cleaning
- Time-based feature engineering
- Forecast model
- Visualization of future sales

Business Value
Businesses can use these predictions to plan inventory and staffing.
